# DEK Controller

Application Windows gratuite de DEK DEV pour diagnostiquer, calibrer et optimiser une manette,
directement depuis le PC :

- stick drift et centrage
- courbes de sticks et sensibilité
- deadzones
- gâchettes et activation
- circularité et précision
- latence et fréquence de réponse
- tests et état de la manette

Pas besoin d'une manette haut de gamme pour gagner en réactivité : l'application tire le maximum
de la vôtre, sans changer de matériel. Une manette haut de gamme garde son avantage matériel, et
un stick mécaniquement usé ne se répare pas par logiciel.

## Télécharger

Dernière version : <https://github.com/lougiadev-creator/DEK-Controller/releases/latest/download/DEK-Controller.exe>

Windows 10 / 11, 64 bits. L'empreinte SHA-256 de chaque fichier figure dans les notes de la Release.
Windows peut afficher un avertissement SmartScreen pour une application non signée :
« Informations complémentaires », puis « Exécuter quand même ».
